# 🐨 코알라 하강 게임 - 스피드 에디션

⚡ **높은 속도감의 웹 기반 게임!** 코알라가 523,000m 높이에서 빠르게 떨어지면서 장애물을 피하고 아이템을 수집하는 게임입니다.

## 🎮 게임 방법

### 조작법
- **← 왼쪽 화살표 키** 또는 **A 키**: 왼쪽 이동
- **→ 오른쪽 화살표 키** 또는 **D 키**: 오른쪽 이동

### 게임 요소

| 요소 | 설명 | 말풍선 | 효과 |
|------|------|--------|------|
| 🐨 | 플레이어 (코알라) | - | - |
| ❤️ | 하트 | ✅ 야 기분좋다! | 목숨 +1 |
| ☄️ | 운석 | ❌ 부끄러운줄 알아야지! | 목숨 -1 |
| 🍌 | 바나나 | ❌ 아 이것도... | 속도 50% 감소 (5초) |

### 목표
- 🚀 빠르게 떨어지면서 최대한 오래 살기
- ❌ 나쁜 아이템(운석, 바나나)을 피하기
- ✅ 좋은 아이템(하트)을 수집하기
- 목숨 3개로 시작하며, 모두 잃으면 게임 오버

## ⚡ 게임 특징

✅ **높은 속도감!** - 코알라와 아이템이 빠르게 떨어짐
✅ **아이템이 더 빠름** - 코알라보다 30% 더 빠르게 떨어짐
✅ 523,000m부터 시작
✅ 나쁜 아이템(운석, 바나나) 비중 높음
✅ 게임이 진행될수록 하트 확률 증가
✅ 말풍선으로 아이템 충돌 표시
✅ 스코어 끊임없이 쭉 정리 (50개 기록 유지)
✅ 파란 하늘 배경 + 흰 구름

## 📊 게임 인터페이스

### 왼쪽: 게임 화면
- 파란 하늘 배경과 하얀 구름들
- 빠르게 떨어지는 코알라
- 현재 해발 높이 표시
- 충돌 시 말풍선 표시
- **아이템 범례** (왼쪽 하단)

### 오른쪽: 정보 패널
- **현재 상태**: 해발 높이, 점수, 속도, 남은 목숨
- **기록**: 지금까지의 최고 점수 기록 (50개 유지, 자동 저장)

## 💾 점수 기록

게임이 끝나면 점수가 자동으로 저장됩니다.
- **50개의 기록**을 유지합니다.
- 브라우저의 로컬 스토리지에 저장되므로 삭제되지 않습니다.
- "다시 시작" 버튼으로 새 게임을 시작할 수 있습니다.

## 🎨 게임 커스터마이징

게임을 수정하고 싶다면, `game.js` 파일을 텍스트 에디터로 열어서 수정하면 됩니다.

**속도 조절:**
- `const INITIAL_SPEED = 150;` - 초기 속도 (숫자가 클수록 빠름)
- `const ITEM_SPEED_MULTIPLIER = 1.3;` - 아이템 속도 배수

**생명 개수 변경:**
- `gameState.lives = 3;` 부분을 다른 숫자로 수정

**장애물 출현 빈도:**
- `if (Math.random() < 0.04)` 의 0.04 값 수정 (클수록 자주 출현)
