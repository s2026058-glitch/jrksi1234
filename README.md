# 🐨 코알라 하강 게임

재미있는 웹 기반 게임! 코알라가 52,300m 높이에서 떨어지면서 장애물을 피하고 아이템을 수집하는 게임입니다.

## 🎮 게임 방법

### 조작법
- **← 왼쪽 화살표 키** 또는 **A 키**: 왼쪽 이동
- **→ 오른쪽 화살표 키** 또는 **D 키**: 오른쪽 이동

### 게임 요소

| 요소 | 설명 | 효과 |
|------|------|------|
| 🐨 | 플레이어 (코알라) | - |
| ☄️ | 운석 | 목숨 -1 (충돌 시) |
| 🍌 | 바나나 | 속도 50% 감소 (5초 동안) |
| ❤️ | 하트 | 목숨 +1 |

### 목표
- 최대한 오래 떨어지면서 점수를 높이기
- 운석을 피하고 아이템을 수집하기
- 목숨 3개로 시작하며, 모두 잃으면 게임 오버

## 🚀 실행 방법

### 가장 쉬운 방법 (추천) 👍

1. 다운로드한 `jrksi1234` 폴더 열기
2. **`index.html` 파일 더블클릭**
3. 게임 시작! 🎮

### 상세 설명

**Windows:**
- 파일 탐색기 열기
- `jrksi1234` 폴더 찾기
- `index.html` 파일 더블클릭 또는 우클릭 → 다음으로 열기 → Chrome/Firefox

**Mac:**
- Finder 열기
- `jrksi1234` 폴더 찾기
- `index.html` 파일 더블클릭 또는 우클릭 → 다음으로 열기 → Safari/Chrome

**Linux:**
- 파일 매니저 열기
- `jrksi1234` 폴더 찾기
- `index.html` 더블클릭 또는 우클릭 → Chrome/Firefox로 열기

## 📊 게임 인터페이스

### 왼쪽: 게임 화면
- 파란 하늘 배경과 하얀 구름들
- 코알라가 떨어지는 장면
- 현재 해발 높이 표시

### 오른쪽: 정보 패널
- **현재 상태**: 해발 높이, 점수, 속도, 남은 목숨
- **기록**: 지금까지의 최고 점수 기록 (자동 저장)

## 💾 점수 기록

게임이 끝나면 점수가 자동으로 저장됩니다.
- 최대 10개의 기록을 유지합니다.
- 브라우저의 로컬 스토리지에 저장되므로 삭제되지 않습니다.
- "다시 시작" 버튼으로 새 게임을 시작할 수 있습니다.

## 🎨 게임 커스터마이징

게임을 수정하고 싶다면, `game.js` 파일을 텍스트 에디터로 열어서 수정하면 됩니다.

**난이도 조절:**
- 초기 속도 변경: `const INITIAL_SPEED = 100;` (숫자가 클수록 어려움)

**생명 개수 변경:**
- `gameState.lives = 3;` 부분을 다른 숫자로 수정

**장애물 출현 빈도:**
- `if (Math.random() < 0.02)` 의 0.02 값 수정 (클수록 자주 출현)
